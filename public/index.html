Conexão com o Chatwoot

Passo a passo no Chatwoot

  1. Configurações → Integrações → Webhooks → Adicionar novo webhook.
  2. Cole a URL do webhook acima e marque o evento Mensagem criada (message_created).
  3. Pronto: quando o paciente tocar num botão, o Chatwoot avisa este sistema, que manda a próxima mensagem.
  4. Ao terminar o fluxo, a conversa recebe a etiqueta fluxo-concluido e uma nota interna com as respostas. Se o paciente pedir atendente ou travar, recebe atendimento-humano.
